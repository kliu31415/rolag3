Benchmarks

Setup:
-i9 11980HK
-RTX 3080 laptop GPU

Test 1
-quadrilateral vertexes (30, 30), (80, 20), (70, 40), (50, 50)
-2 triangle renders per quad, 6 vertexes sent to GPU. Each vertex is 6 f32s, so 24 bytes.
-area 750px
-163840 quads, and almost all quads were on screen (very little can be clipped)
-debug build: 6/7fps (likely with dedicated GPU, but unsure)
-release build: 20 fps with dedicated GPU, 12 with integrated
-fps: 20 with release build, 6/7 with debug build
-Unsure if this used a discrete GPU or not
-Might be CPU bound; with the current logic, every frame, one allocation occurs per quad drawn

Test 2
-Running Rofiz test rooms as usual, but also drawing 10000 copies of "fps=xx", where xx is the fps
-font rasterization is theoretically cached
-100 pt font, cosmic text default font
-2 to 3 fps in debug mode
-27 fps in release mode

Test 3
-30x30 room
-Spawn ~1000 projectiles that are clearly off-screen and don't overlap with any units
-Runs at 3000 ticks/s in release mode (~57-60 fps at 50 ticks/frame)
-Runs at 440 ticks/s in debug mode (~22 fps at 20 ticks/frame)
